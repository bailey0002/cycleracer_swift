# KERB: GALACTIC — Game Design Document (current state, 2026-10-17)

A living GDD: what the game *is today*, read from the code on `master` (PR #6 merged; PR #7 `claude/garage`
is open and on the phone, noted where it changes a number). Each element carries a status tag. It summarises;
the sources of truth stay where they are: `CLAUDE.md` (code map and gotchas), `SpeederProto/docs/polish-log.md`
(what was built, with captures), `docs/game-direction.md` (why a mission runner), `docs/assessment-2026-09-27-story.md`
(the arc), `docs/arena-next.md` (the Grid's open proposals), `SpeederProto/README.md` (harness).
Re-read it before a phone test; rewrite the status column after one. The interactive map is `docs/gdd-map.html`.

**Status tags.** `BUILT` in the code · `CAPTURED` verified by the project's harness (Mac capture frames, simulator
sheets, the 14 headless tests) with evidence in `Captures/` or the log · `PHONE` judged on the iPhone 12 with the
Backbone · `UNJUDGED` built but never seen on the phone · `DESIGNED` in a doc, not in code · `GAP` missing.

## 4. Game flow (`Scene/FrontEnd.swift`, `Scene/GameController.swift`)

```
SPLASH (launch logo, Core Animation loader timed from the last launch; "Hideaway" starts here)
 → TITLE  (wordmark, camera drift; CONTINUE / START · CONTINUE SAVE · RIDERS · FREE PLAY · MESSAGES · SETTINGS)
   first run: → RIDERS (◀▶ rider, A) → STORY (10 beats, A hurry, B skip) → CALLSIGN + LIVERY (A = RIDE)
 → CHAPTER CARD (first job of a chapter, once; A)
 → BRIEFING  (contact, brief, goal line, best / silver / gold, flags, GARAGE rows, INBOX chips; A = ACCEPT)
   duel: → RIVAL INTRO card (3.6 s: name, temper, record, taunt; A skips)
 → RUN (HUD; Menu = PAUSE: RESUME · SAVE GAME · MESSAGES · SETTINGS · QUIT TO TITLE)
 → RESULT card: success (title, payout, rank, flags, the debrief, the contact's reactive line; A = NEXT JOB)
             or failed (reason, the contact's line; A = one-tap RETRY)
 → next BRIEFING (the inbox moved to the next open job)
FREE PLAY → WORLDS (Neon City / Sunset Canyon / The Grid) → run card → endless run or a first-to-three match → MATCH RESULT card → next rival
```
`BUILT CAPTURED PHONE` for the whole loop (Mark's 2 Oct play produced the fresh-start and run-card items; the
rebuild re-queue and first-run routing fixes are `CAPTURED`). Interludes, a hub scene: `DESIGNED`. The screen stack
is `GameController.screens`; one row model (`menuRows`) drives pad, keyboard and touch. `SPEEDER_SCREEN=` opens any
screen for captures.

**Fresh start + manual save** (`Missions/SaveSlot.swift`) `BUILT PHONE`: every launch clears the live progress keys so
riders → story → callsign play every time; SAVE GAME (pause, SETTINGS) snapshots them into one slot; CONTINUE SAVE on
the title loads it. `SPEEDER_KEEP_PROGRESS=1` skips the clear.

### 5.3 Rules that bite
- An idle pad does not own the steering: touch and keyboard still work with a pad connected.
- Boost disarms at 2 % energy and re-arms at 15 % (hysteresis), so a held trigger on an empty hull does not flicker.
- Cruise speed is locked while a job is live (the windows and the pursuer are tuned to 45 m/s).
- A hit takes 40 % of the speed, 70 ms of hit-stop, a sideways recoil (0.45 s) and `upgrades.hitDamage` of the bar.
- Pressing the lane limit (± 6.9 m) or the conduit wall scrapes: sparks, 0.08 bar / s.
- Haptics: the pad's own actuators when it has them, else the phone's (the Backbone has none, so the phone taptics
  do the work); a continuous engine hum from speed and boost; HAPTICS off stops everything.
- Demo mode pulses the accept button (0.5 s on, 1 s off) because a held accept has no edge.

## 6. Core mechanics

### 6.1 The corridor vehicle (`Scene/SpeederController.swift`, `Scene/WorldScroller.swift`) `BUILT PHONE`
The world scrolls past a vehicle fixed at z ≈ 0 in 40 m segments (eight live). Cruise 45 m/s (`FXSettings.cruiseSpeed`),
boost × 1.8, speed normalised against 110. Steering is a velocity (`7.5 + 7 × speedNorm` m/s), altitude a second
axis (hover 1.05 m to 5.6 m, climb 6.5 m/s, settles only below 1.6 m). Lane limit ± 6.9 m; the fork's divider is a
lane limit past the nose (`wedgeLimit`). Section transitions are blends (`tubeBlend`, `enclosure`, `forkBlend`):
in a conduit the vehicle is clamped to a cylinder (radius 6 m − 0.7, centre 6 m) and rolls toward the wall it hugs.
Obstacles are pooled per segment in 1–3 rows across four lanes with two lanes always open; blocks are jumped,
drones ducked or shot, gates flown over. Plasma bolts: 95 m/s every 0.14 s (`Scene/Weapons.swift`), a white core in a
cyan sheath with Kenney's laser / blast clips. Hoverboard: the same controller with KERB's board, the rider posed by
`Scene/RiderRig.swift` (no IK), 1.35 × scale, camera lift 0.9 / 1.9 m.

### 6.2 The job state machine (`Missions/MissionRunner.swift`) `BUILT CAPTURED PHONE`
`chapter → briefing → (rivalIntro) → running → success | failed`, plus `freePlay`. Per frame the runner takes
distance, speed, hits, boost, scrape, kills, beacons and the branch taken.

**One bar** (hull = boost fuel, 0…1, starts full):
| Drain / charge | Value |
|---|---|
| Hit | 25 % → 20 % → 16 % per HULL PLATING level, ÷ rider hull, × 2 on a dive; the HELMET takes the first hit |
| Scrape | 0.08 / s (× 2 on a dive) |
| Boost | 12 % → 9 % → 7 % per second per BOOST COIL level |
| Recharge | 0.035 / s when neither boosting nor scraping |
| Beacon | + 20 % · kill + 5 % |
| Empty bar | checkpoint respawn: hull to 50 %, streak reset, + 4 s on the clock; 2 per job (+ 1 with SPARE CORE); none left = HULL BREACHED |

**Streak score**: a gate every 200 m pays 50 × streak and refunds 1.5 s of the window; a beacon pays 150 × streak;
a kill 25 × streak without climbing it; the streak climbs to 8 and a hit resets it to 1. `maxScore` is the clean run
(gates and beacons climbing to the cap, beacons' extra 100 and kills at the cap); silver at 40 %, gold at 70 % of it.
Duels: gold on a win.

**Windows** (27 Sep 2026, from the headless loop): net cruise time at 45 m/s minus the gate refunds, plus 30 %, so
plain cruise arrives with about a quarter of the window left and the FAST flag (a third left) takes some boost.

**Escape**: the pursuer ramps to 47 m/s at 22 m/s²; gap += (speed − pursuer) × dt; CAUGHT at 4 m. Plain cruise is
caught by design.

**Flags**, once per job, kept forever: CLEAN (no hits), FAST (a third of the window left), GOLD (gold rank). They
open the side offers.

### 6.3 The light cycle (`Arena/LightCycle.swift`, `Arena/ArenaController.swift`, `Arena/TrailSystem.swift`) `BUILT PHONE`
Kinematic: the game owns speed, heading and position; lean, pitch and the damped visual heading are presentation.
Armagetron's accel curve: base 36 m/s, boost a burst at 34 m/s² up to 68, brake to 15, hard cap 96; decay toward
base at 0.30 from above (a grind's gain is kept a while) and 5.0 from below; every quarter turn multiplies speed
by 0.95; turn rate 2.1 rad/s, 25 % slower at full boost. Jump 12.5 m/s under 24 m/s² gravity, trail 2.2 m high.
The rival rides the same physics with a shorter burst (boost 54 at 24 m/s², cap 62: its 0.16 s decisions cannot
handle more; keep it that way).

| Arena rule | Value |
|---|---|
| Energy (boost meter) | starts 0.6; boost drains 0.22 / s, idle recharge 0.03 / s; a grind refills 0.35 × grind / s (0.12 while boosting); the rival has the same budget |
| Grind | proximity accel `22 / (1.2 + d) − 22 / 6.2`, zero beyond 5 m; a wall on both sides (tunnel) × 1.5; leaving a hard grind kicks 10 m/s |
| Edge meter (rubber) | drains 1.4 × (1 − clearance / 0.45) / s near contact, recharges 0.15 / s; a shallow hit (> 0.86 along) with edge > 0.3 deflects at a cost of 0.45; empty edge or a square hit derezzes |
| Trails | sampled every 1.2 m at the tail, forced at snap corners, spatial hash 10 m, swept-line collision with a vertical band; lengths short 220 m / long 420 m / endless (SETTINGS default long); a derez breaches every dynamic wall within 4 m |
| Pads | 4 boost (+ 22 m/s, + 15 % energy, SURGE) and 2 slow (× 0.6) on the floor plus a chain of 4 along the deck; radius 4.2 m, one trigger per 1.5 s |
| Pickups | PHASE (A: pass through one wall within 5 s) · PULSE (A: erases the newest stretch of your own trail, a pulse runs back) · CHARGE (deck only, on contact: energy to full, + 20 m/s) |
| Sumo zone | after 25 s of play a 70 m circle opens at (0, 30) and shrinks to 16 m over 20 s; outside − 0.07 / s and an empty bar derezzes, inside + 0.08 / s; the AI targets it |
| Rounds | either derez ends the round: player's = slow-motion (× 0.35) orbit 3.4 s; rival's = freeze-cam 2.6 s; both the same frame = VOID ROUND; then ROUND n, GO |
| Match | free play first to 3 (`matchTarget`), a duel job sets it out of reach and reads wins / losses itself; MATCH WON / LOST orbit 3.8 s then the result card |
| AI (`Arena/ArenaAI.swift`) | decides every tick (0.30 / 0.16 / 0.10 s by skill, 0.14 / 0.08 / 0.05 when a wall is within `14 + 0.25 × speed` m), probes headings through the hash over 55 / 80 / 100 m with noise 8 / 5 / 2, an occupancy-grid space term (6 m cells), a loop guard, a temper goal (boxer: the point ahead of you; runner: open ground and the next pad; hunter: your tail and a grind on your trail), the zone and the ramps; respawns 4 s after a derez at the most open spot |

### 6.4 Camera, FX, motion (`Scene/CameraRig.swift`, `Rendering/PostProcessor.swift`, `Rendering/PostFX.metal`) `BUILT PHONE`
Chase rig 2.5 m up, 5.8 m back, lens 52 + 14 × speedNorm, a boost kick, lateral inertia, roll from banking, shake

## 8. Objectives and missions

### 8.1 Shapes in code (`Mission.Kind`) `BUILT CAPTURED`
| Kind | Goal | Fail | Payout extra |
|---|---|---|---|
| **delivery** (RELAY) | reach the drop inside the window | TIME OUT · HULL BREACHED | — |
| **search** (SWEEP) | fly through N of M beacon rings, some at altitude (red, 1.9 m, a missed ring goes grey and recedes) | SWEEP INCOMPLETE | + 40 per beacon |
| **escape** (RUN) | keep the pursuer behind you to the relay | CAUGHT | + 2 per metre of gap |
| **salvage** (SALVAGE) | destroy N marked drones / crates before the drop | TARGETS MISSED | + 30 per kill |
| **dive** (DIVE) | a conduit time trial, no weapons, hull bruises × 2 | as delivery | hull bonus counted twice |
| **duel** (DUEL) | The Grid, first to 2 / 3 derezzes of the named rival | DEREZZED n TIMES | + 100 × (wins − losses) |

Every corridor payout: `basePay + 3 × seconds left + 2 × hull % + kind bonus + score / 20`; a replay of a cleared job
pays half; a side offer's bonus pays once on top. The seven kinds in `docs/game-direction.md` minus heist: heist is
`DESIGNED`.

## 11. Architecture and backend

- **Stack**: Swift 5 mode (`SWIFT_STRICT_CONCURRENCY: minimal`), SwiftUI over an `ARView` (`cameraMode: .nonAR`), RealityKit
  for rendering only, Metal post pass via `renderCallbacks.postProcess`, `LowLevelMesh` trails, `CustomMaterial`
  surface shaders. Project generated by xcodegen from `project.yml` (run `xcodegen generate` after adding files or
  the bundle silently lacks them). Build with Xcode 26.6 (`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`;
  the Xcode 27 beta has no Metal toolchain). Targets: `SpeederProto-macOS`, `SpeederProto-iOS` (team HNBN55RN29),
  `SpeederProtoTests` (hosted by the Mac app). No packages, no server.
- **Loop**: `GameController.tick` at the display rate with a fixed 60 Hz step in captures; hit-stop scales dt by 0.15
  for 70 ms; the front end sits on a `screens` stack; scene rebuilds go through `requestRebuild()` (curtain first),
  re-queued if one is running.
- **Layers** (`Sources/`): `App` (SwiftUI app) · `Scene` (GameController, WorldScroller, TrackProgram + TrackComposer,
  SpeederController, RiderRig, CameraRig, Theme, GameMode, Weapons, AvatarActor, FrontEnd) · `Arena` (ArenaWorld,
  ArenaTerrain, LightCycle, TrailSystem, TrailRenderer, ArenaController, ArenaAI, Rival) · `Missions` (Mission,
  MissionRunner, Debrief, MessageLog, Player, Riders, SaveSlot, MissionProps) · `Rendering` (MaterialFactory,
  ProceduralTextures, ArtLibrary, Meshes, PostProcessor, PostFX.metal, Shaders.metal, FrameCapture) · `Audio`
  (SoundEngine, Soundtrack) · `Views` (GameView, HUDView, FrontEndView, StoryIntroView, Input) · `Utilities`
  (FXSettings, Platform). About 17,000 lines of Swift and Metal.
- **Data**: no JSON; the catalogue, the riders, the recipes and every constant are Swift (`Mission.deliveries`,
  `Roster.all`, `Theme`, `ArenaTerrain.garage`). Assets: `Speeder.usdz` (Piotr Pisiak, CC-BY-4.0), `Board.usdz`,
  `Rider_*.usdz` + stills + mp4 clips, `Avatar.usdz`, `Resources/Art/*.png`, `Resources/Audio/`, `Resources/Fonts/`,
  `Assets.xcassets` (icon and launch logo rendered by `swift Tools/render-brand.swift`).
- **Persistence** (`UserDefaults`, no prefix for progress): `credits`, `missionIndex`, `cleared`, `cleared.mask`,
  `upgrades` (bit-packed), `rank.<job>`, `flags.<job>`, `record.<rival>.w/.l`, `said.<contact>.<key>`,
  `chapter.seen.<n>`, `offer.<id>.done`, `messages`, `messages.read`, `callsign`, `livery`, `rider.id`, `story.seen`;
  the save slot `save.slot` + `save.time`; settings `prefs.music/effects/haptics/quality/gridSteering/vehicle/tracks/devUnlocked`;
  the loader's `load.<theme>.<stage>` timings. iCloud sync: `GAP`. `SPEEDER_RESET_PROGRESS=1` and SETTINGS > RESET
  PROGRESS clear progress but keep identity.
- **Content pipeline**: Blender 5.0 GLB / FBX → USDZ (`export_animation`, `export_armatures`, `export_textures_mode='NEW'`);
  KERB's `Tools/convert_cc.py` for CC5 riders; `render-brand.swift` for the icon; GPT / ChatGPT renders cropped with
  ffmpeg into `Resources/Art/`. Binary assets' home: OneDrive `Stratum/04 Mandatum/GS-GAME-013/`.
- **Performance**: iPhone 12 ready 3.9 s after launch in Release (Debug about 4 × slower: the procedural textures are
  Swift pixel loops); the loader's stages are timed from the last launch. Mac Debug 50–60 fps at 2560 × 1440 with the
  post pass; simulator 60 fps with ~180 arena entities (depth reads NaN there, the post pass falls back to screen-space
  fog). Phone fps and thermals over a long run: `UNJUDGED` (README's own next step). Bundle size not recorded here.
  Four Mac captures at once drop to 15–25 fps and lose late capture times.
- **Testing**: `Tests/MissionLoopTests.swift`, 14 tests, a 60 Hz headless loop over `MissionRunner` with rider profiles
  (cruise, clean, clean+boost, few hits, sloppy, reckless), the balance table asserting the rank shape;
  `xcodebuild test -scheme SpeederProto-macOS` with `SPEEDER_TESTS=1` (the app becomes a bare host). Visual
  verification: `Captures/polish/capture.sh <dir> <s> ENV=VAL` (fixed 60 Hz step, `-ApplePersistenceIgnoreState YES`,
  under `caffeinate`), `simshot.sh` for simulator HUD shots, ~45 `SPEEDER_*` switches (`SPEEDER_DEMO`, `_MISSION`,
  `_SCREEN`, `_ARENA_*`, `_CHECK_NAN`, …). `screencapture` is blocked; frames are read as PNGs.
- **Repo / ops**: GitHub `bailey0002/cycleracer_swift` (private), default `master` (GOVERNANCE drift, owner decision
  pending), PRs #1–#7 (#7 open), registry GS-GAME-013, governance in `grey-stratum-ops`; `Captures/` (~1.1 GB) is
  committed and the repo is ~1.3 GB, so new captures stay out of git. Memory pinned by path (never rename the folder).
